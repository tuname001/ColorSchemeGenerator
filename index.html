ヘルプ

メイン機能

生成現在の設定・モードに基づき、新しい配色を新規作成します。
ランダムモードやパラメータをランダムに変更して新しい配色を作ります。
更新左端の色をベースとして維持したまま、現在の設定で配色を再生成します。
保存現在のパレットをサイドバーの「ストック一覧」に保存します（最大20個）。
Web現在の配色を適用したWebサイトUIのライブプレビューを表示します。
切替Webプレビュー時の文字色・デザイン適用ロジックを切り替えます。
一括ロックすべての色領域のロック状態を一括で切り替えます。
幅リセット変更された各色領域のサイズ比率を均等な初期状態にリセットします。
目盛り表示画面下部に配色の位置を確認できる目盛り線の表示・非表示を切り替えます。
戻る / 進む配色の変更履歴を一つ前に戻す（Undo）、または一つ後に進める（Redo）ことができます。
色領域移動色領域をドラッグ操作することで、直感的に配色の並び順を入れ替えられます。
サイズ変更色の境目にあるハンドルをドラッグすることで、各色の占める幅比率を変更できます。
ロックボタン色領域内の南京錠ボタンを押すとその色を固定でき、再生成やランダム変更時にも変更されなくなります。

編集パネルの機能と仕様

表示モード

グラデーション表示（色の境目を滑らかにつなぐ）と分割表示（色境界を明確に区切る）を切り替えられます。また、RGB / HSV / OKLCH ボタンでグラデーションの補間基準となる色空間を選択できます。

配色カテゴリ

3つのカテゴリから選択して配色を生成できます。

1. OKLCH色彩トーン配色

色相ステップ・彩度ステップ・明度ステップのスライダーを調整し、指定した一定のルールに基づいて規則的な階調の配色を作成できます。

2. 色彩理論・体系配色

色彩学やデザイン理論に基づいた体系的な配色ルールを適用できます。選択項目は以下の通りです。

  • カマイユ (微小変化)
  • フォカマイユ (類似変化)
  • ドミナントカラー (同一色相)
  • ドミナントトーン (同一トーン)
  • トーンオントーン (明度対比)
  • トーンイントーン (類似トーン)
  • トーナル配色 (ダルトーン系)
  • アクセントカラー (対照色強調)
  • ダイアード / 2色補色 (2色)
  • ビコロール配色 (2色)
  • トライアド / 3等分 (3色)
  • スプリットコンプリメンタリー (3色)
  • トリコロール配色 (3色)
  • セパレーション配色 (3色)
  • テトラード / 4等分 (4色)
  • ペンタード / 5等分 (5色)
  • ヘクサード / 6等分 (6色)
3. イメージワード配色

特定のテーマや感情、世界観を表現するカラーパレットを生成します。選択項目は以下の通りです。

  • カジュアル
  • クラシック
  • クリア
  • シック
  • ダイナミック
  • モダン
  • ウォームナチュラル
  • フレッシュナチュラル
  • エレガント
  • ロマンチック
  • ナチュラル
  • ゴージャス
  • フェミニン
  • ダンディ
  • エスニック
  • レトロ
  • ポップ
  • ミニマル
  • サイバー
  • 和風
  • パステル
調節

ロックされている色も含め、パレット全体の色の見た目（色相・彩度・明度）を一括で調整できます。

単色調整

選択中（クリック/フォーカス）の色領域に対してのみ、個別に色相・彩度・明度を微調整できます。確定（保存）ボタンで調整を固定できます。

リアルタイムプレビュー

サイドバー左端に縦長グラデーションを表示し、ドラッグ操作で直感的に色の順序を並べ替えられます。

色覚多様性シミュレーター

1型（赤不全）、2型（緑不全）、3型（青不全）の色覚での見え方をリアルタイムにシミュレート検証できます。

ストック機能

気に入った配色を最大20個まで保存可能。ドラッグで並べ替え、クリックで再読み込み、上書き保存や削除が可能です。

出力形式

共有URL、CSS変数、Tailwind、SCSS、iOS Swift、Android XML、Flutter、HLSL/GLSL、Unity C#、Godot、Three.js、PNG画像、JSON、CSVに対応しています。

ショートカットキー一覧

  • Space 生成
  • R ランダム
  • Ctrl + Z 一つ前に戻る
  • Ctrl + Y 一つ後に進む
  • Ctrl + S 保存
  • スワイプ (左右) 配色切り替え
